# 🧠 AI-Generated VS Real Images Classification

Проект по дисциплине "Машинное обучение и обработка данных" — сервис, позволяющий определить сгенерированно ли изображение исскуственным интеллектом или является настоящим.

В данном проекте реализована модель гибридная нейросетевая модель, сочатающая CNN и CLIP VIT, для решения задачи бинарной классификации.  Модель обучалась на данных [датасета](https://www.kaggle.com/datasets/tristanzhang32/ai-generated-images-vs-real-images) и интегрирована в веб-приложение, позволяющее самостоятельно загрузить и проверить фотографию.

**Цель проекта:**
Цель проекта — разработать и обучить нейросетевую модель для бинарной классификации изображений с целью определения, является ли изображение сгенерированным искусственным интеллектом или реальным, и интегрировать ее в веб-сервис для практического использования.

**Протестировать реализованный сервис можно по [ссылке](http://178.72.170.234/).**

## Описание данных
Датасет с платформы Kaggle состоит из 60,000 изображений, из которых:
- Сгенерированные изображения (30,000): 
  - 10,000 изображений из Stable Diffusion 
  - 10,000 изображений из MidJourney 
  - 10,000 изображений из DALL-E 
- Реальные изображения (30,000): 
  - 22,500 изображений из Pexels и Unsplash 
  - 7,500 изображений из WikiArt

## Архитектура модели

В проекте используется гибридная модель **CLIP ViT + Fourier CNN → классификатор**.

CLIP Vision Transformer извлекает семантические признаки из RGB-изображения, отражающие высокоуровневое содержание и контекст сцены. Параллельно сверточная нейронная сеть (CNN) работает с частотным представлением изображения, полученным через преобразование Фурье (FFT), и выявляет спектральные артефакты, характерные для изображений, сгенерированных нейросетями.

Далее признаки из пространственной (CLIP ViT) и частотной (Fourier CNN) областей объединяются и подаются в классификатор, который принимает финальное решение о классе изображения.

Такой подход эффективен, поскольку генеративные модели способны хорошо воспроизводить визуальную семантику, но часто оставляют заметные следы в частотной области. Комбинация пространственных и спектральных признаков повышает точность и устойчивость модели к различным типам генерации.

Итоговое качество модели на тестовой выборке составляет **97% accuracy**.
